# Cryptography Algorithms

Classical cryptography implementations in Python.

## Files

| Script | Description |
|--------|-------------|
| `caesar_cipher_223311019.py` | Encrypts/decrypts using Caesar cipher (shift cipher) |
| `brute_force_attack_223311019.py` | Brute force attack on Caesar cipher (tries all 25 keys) |
| `monoalphabetic_cipher_223311019.py` | Substitution cipher with custom alphabet mapping |
| `letter_frequency_223311019.py` | Analyzes letter frequency in ciphertext |

## Usage

```bash
python caesar_cipher_223311019.py
python brute_force_attack_223311019.py
python monoalphabetic_cipher_223311019.py
python letter_frequency_223311019.py
```

- Python 3.x
